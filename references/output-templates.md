# 适老化话术库

所有输出照抄这里的句式。改动前先对照 §9 十二条无障碍规约。

---

## 一、开场

```
您好，我来帮您点麦当劳。
```

**一次只问一件事。** 禁止："您好，请问您要找附近的门店还是外送到家，另外有什么忌口吗？"

---

## 二、第 1 步 · 定地方

### 2.1 模式提问

```
您是自己到店里吃，
还是要送到家里？
```

变体（子女代下单时自动识别）— 用户说了「给我妈点」「送到我爸家」直接进模式 B，不用问。

### 2.2 模式 A 门店呈现

```
我们选这家店：

  {storeName}

  {address}
  走路 {walkMinutes} 分钟
  现在开门，到 {closingTime}

是这家吗？
```

示例：

```
我们选这家店：

  麦当劳上海福州路餐厅

  福州路 666 号
  走路 5 分钟
  现在开门，到晚上 11 点

是这家吗？
```

**距离话术的五种分档**（由 `scripts/a11y_format.py walk` 决定）：

| 走路时间 | 话术 |
|---:|---|
| 1 分钟 | 就在跟前 |
| 2–5 分钟 | 走路 {n} 分钟就到 |
| 6–10 分钟 | 走路 {n} 分钟 |
| 11–16 分钟 | 走路要 {n} 分钟，稍微有点远 |
| > 16 分钟 | 走路要 {n} 分钟，太远了。要不要改成送到家？ |

### 2.3 营业时间话术

| 情况 | 话术 |
|---|---|
| 正常营业 | 现在开门，到{晚上 11 点} |
| 24 小时 | 这家店全天都开 |
| 剩余 30–60 分钟 | 这家店 {n} 分钟后关门，要不要现在就点？ |
| 剩余 ≤30 分钟 | 这家店再有 {n} 分钟就关门了，可能来不及。要不要换一家，或者送到家？ |
| 全部打烊 | 附近都关门了。要不要明天早点给您点？最早的一家 {早上 6 点半} 开门。 |

**把 24 小时制换成口语：** `23:00` → 「晚上 11 点」，`06:30` → 「早上 6 点半」，`17:00` → 「下午 5 点」。

### 2.4 模式 B 地址

```
送到这个地址吗：

  {contactName}
  {fullAddress}

是这个吗？
```

无地址时：

```
还没有地址。
我帮您加一个，您说，我记。
```

## 三、第 2 步 · 定吃的

### 3.1 复用上次（优先级最高）

```
上次您点的是 {productName}。
还是来这个吗？
```

用户答「好」→ 直接进第 3 步，**跳过整个选餐过程**。

### 3.2 三选一

```
有 {n} 个，您挑一个：

  一、{name}
      {moneyChinese}
      {一句话说明}

  二、{name}
      {moneyChinese}
      {一句话说明}

要第一个吗？
```

一句话说明的写法（**只写食物的自然构成，不写营销标签**）：

| ✅ 对 | ❌ 错 |
|---|---|
| 鸡肉汉堡，薯条，饮料 | 爆款三件套，立省 13 元 |
| 一个汉堡，一份薯条，一杯饮料 | 经典精选，超值组合 |
| 汉堡包配薯条和可乐 | 人气之选，限时供应 |

序号用中文数字：**一、二、三**（不用 `1.` `2.`，读屏会读成"一点""二点"）。

### 3.3 凑不满时

只有一个合适时**不要硬凑**：

```
我挑出来一个合适的：

  吉士汉堡包套餐
  26 元
  一个汉堡，一份薯条，一杯饮料

要这个吗？
```

## 四、第 3 步 · 对一对

### 4.1 两个开关 —— 先查能给几个，最多给两个

**先确认 `choices[].supportModify`，能改什么给什么。不要默认"去酱"一定可用。**

| 轮次 | 能给的开关 | 实测可用性 |
|---|---|---|
| 饮料（round 3） | 少冰 / 去冰 | ✅ 几乎都支持 |
| 主食（round 1） | 去酱 / 去生菜 | ⚠️ **仅汉堡类套餐**。炸鸡类（如麦乐鸡套餐）`supportModify=false`，**没有酱可调** |
| 小食（round 2） | —— | ❌ 实测全部不可调 |

主食可调时（汉堡类）两句分开问：

```
要不要让店里少放点冰？

要不要让店里别放酱？
```

主食不可调时（炸鸡类）**只问一句**：

```
要不要让店里少放点冰？
```

> 🔴 对用户承诺系统做不到的事，比不问更糟。

用户提了其他需求（忌香菜、控糖、牙不好）才引入对应调整，措辞同理：

```
要不要把可乐换成无糖的？
（这个不加钱）
```

### 4.2 复述卡（模式 A）

```
好的，我们再对一遍：

  店：{storeName}
      {address}

  吃的：{套餐名}
        {构成说明}
        {调整1}
        {调整2}

  钱：{moneyChinese}

  拿：去店里柜台拿

对了吗？
```

### 4.3 复述卡（模式 B）

把「拿」替换成：

```
  送：送到家，大概 {n} 分钟到
```

**并且金额必须拆开说**（外送实付比标价贵约 25%，只报商品价会让父母以为被多收钱）：

```
吃的：{productPrice} 元
送到家：加 {deliveryPrice} 元
装盒：加 {packingPrice} 元
一共：{price} 元
```

实测样例：

```
吃的：31 元
送到家：加 6 元
装盒：加 1 元 9 角
一共：38 元 9 角
```

> `calculate-price` 返回的 `productList` 里会多一项「打包服务费」（`920174`，`subtotal` 为 0）。
> 它是系统内部项，**不要念出来**，只按上面四行说。

### 4.3bis 模式 A 补一句：堂食还是外带

`calculate-price` 会返回 `takeWayList`（`eat-in` 堂食 / `locker-out` 外带），**下单必传 code，漏了会失败**。紧接在复述卡后、第二次确认前问：

```
您在店里坐着吃，还是带走？
```

**不解释「店外取餐柜」**，用户问才答。

### 4.4 金额再确认（第 2 次确认）

```
一共 {moneyChinese}。

现在给您下单，可以吗？
```

**这是第二次确认，不能省。** 之后才调 `create-order`。

## 五、给爸妈的一张卡（模式 B 结束时）

```
{称呼}，给你点了麦当劳，一会送到家。

  送到：{fullAddress}
  到了：大概 {n} 分钟内，手机会响
  吃的：{构成说明}
  钱：我这边已经付过了，你不用付钱

  送到了就趁热吃。
  凉了用微波炉热 30 秒。
  不对打我电话。
```

四条硬要求：
1. **必须有「你不用付钱」**
2. **必须有时间预期**
3. **必须有求助出口**
4. **无 emoji、无 Markdown 语法**（微信会显示成乱码）

带健康限制时，第三段调整：

```
  吃的：一个汉堡，一份薯条，一杯无糖可乐
        （可乐换无糖的，医生说的）
        （让他少放冰了）
```

## 六、失败话术

| 情况 | 话术 |
|---|---|
| 门店查询无结果 | 这个位置没找到店。您再说具体一点，比如哪条路？ |
| 所有店都打烊 | 附近都关门了。要不要明天早点给您点？ |
| 地址为空 | 还没有地址。我帮您加一个，您说，我记。 |
| `order-list` 为空 | （静默降级到菜单收敛，什么都不说） |
| 菜单过滤后为空 | 这家店今天没有合适的套餐。我们换一家试试？ |
| 只能推荐需购卡商品 | 这些要先买一张卡才划算。我给您换个不用买的。 |
| 用户答非所问 | 没关系，我们再说一遍。您是自己到店里吃，还是要送到家里？ |
| 用户说「随便」 | 那给您选便宜的：{name}，{money}。可以吗？ |
| 用户说「太贵了」 | 那换这个：{下一便宜的}，{money}。 |
| 用户说「算了」 | 好的，那就不点了。 |

**禁止出现**：「操作失败」「请求错误」「参数异常」「系统返回空」——任何系统语言都要翻成人话。

## 七、数字与时间读法

### 金额（用 `scripts/a11y_format.py money`）

| 原始 | ❌ 不能这么写 | ✅ 这么写 |
|---|---|---|
| `34.5` | ¥34.5 / 34.5 元 | **34 元 5 角** |
| `26` | ¥26.00 | **26 元** |
| `13.9` | ¥13.9 | **13 元 9 角** |
| `0.5` | ¥0.5 | **5 角** |

### 时间（24 小时制转口语）

| 原始 | 口语 |
|---|---|
| `06:30` | 早上 6 点半 |
| `10:00` | 上午 10 点 |
| `12:00` | 中午 12 点 |
| `14:00` | 下午 2 点 |
| `17:00` | 下午 5 点 |
| `19:30` | 晚上 7 点半 |
| `23:00` | 晚上 11 点 |
| `00:00` | 半夜 12 点 |

### 符号替换（第 10 条规约）

| 原始 | 改写 |
|---|---|
| `随心配1+1` | 随心配一一 |
| `麦咖啡™` | 麦咖啡 |
| `【美汁源】黄金橙橙` | 橙汁 |
| `50%-off` | 打五折 |
| `15–25 分钟` | 大概 20 分钟 |

## 八、收尾

模式 A：

```
点好了。

去 {storeName} 柜台，
跟店员说取餐就行。
```

模式 B：见 §五 卡片。

**不复述订单号、不复述门店编号、不复述总价之外的任何数字。**
